# Короткий документ по продукту

## 1. Оценка стоимости на 1 пользователя в месяц

Сценарий:

- пользователь мониторит `30` каналов
- запускает `/digest` `1` раз в день
- используется `Claude Haiku`

### Токены LLM

Для текущей MVP-архитектуры бот не отправляет в модель весь поток постов, а сначала локально сжимает их в shortlist тем. При таком сценарии реалистичный ориентир:

- `1 digest`: около `0.1 цента`
- `30 digest` в месяц: около `3 центов`

Даже если объем входных данных вырастет в несколько раз, LLM все равно останется самой дешевой частью MVP, если shortlist остается компактным.

### Хостинг

Для always-on запуска достаточно небольшого VPS или контейнерного инстанса:

- `4-10 USD / месяц`

Если бот запускается на внутренней машине компании, этот расход почти исчезает.

### Прочее

- локальное хранение JSON / SQLite: `≈ 0 USD`
- Telegram platform fee: `0 USD`
- базовые логи и мониторинг: `0-2 USD`

### Итого

- локальный / внутренний запуск: `≈ 0.03-2 USD / месяц`
- небольшой hosted MVP: `≈ 4-12 USD / месяц`

Главный расход здесь не LLM, а инфраструктура.

## 2. Как продукт можно монетизировать

### Гипотеза 1. Competitive intelligence для founders и PM

- Аудитория: founders, product managers, solo operators
- Боль: вручную читать десятки Telegram-каналов конкурентов и рынка
- Модель: подписка `19-79 USD / месяц`

### Гипотеза 2. Мониторинг для аналитиков и агентств

- Аудитория: research-команды, аналитики, boutique agencies
- Боль: быстро получать ежедневную выжимку по Telegram-native нишам
- Модель: team plan или analyst seats `99-299 USD / месяц`

### Гипотеза 3. Вертикальный intelligence-продукт

- Аудитория: crypto, OSINT, региональные медиа, gaming-community
- Боль: нужен не общий summarizer, а нишевой high-signal digest
- Модель: premium vertical package с шаблонами, watchlists и архивом

## 3. Первый канал привлечения

Если запускать продукт коммерчески, первым каналом привлечения я бы выбрал сам Telegram.

Почему:

- целевая аудитория уже находится внутри Telegram
- ценность продукта легко показать за 1-2 минуты
- боль формулируется очень просто: “не читать 50 каналов руками”
- продукт органично продвигается через demo, кейсы и прямой outreach

Практически это выглядело бы так:

1. короткое demo-видео
2. простой landing page
3. ручной outreach в релевантные Telegram-сообщества и рабочие чаты

Для такого MVP это самый быстрый канал проверки спроса.
